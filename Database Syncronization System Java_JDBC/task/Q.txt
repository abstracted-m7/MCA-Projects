`task`
 Develop a Java application that synchronizes in-memory collection data with a database. The program should store records initially in Java collection objects, allow modifications at runtime, and then persist the updated data into a database table using JDBC. This application should demonstrate how collections act as temporary data holders before permanent storage.

`Let's Begin`

# Title:  In-Memory Collection to Database Synchronization System (Java + JDBC)

#Project Overview

1. System Architecture:
User Interface Module
        │
        ▼
Service Layer (Business Logic)
        │
        ├── Collection Layer (ArrayList)
        │
        └── Database Access Layer (DAO)
                    │
                    ▼
            JDBC Connectivity
                    │
                    ▼
                MySQL Database

2. Technologies Used
    Java Core, OOP
    JDBC API
    phpMySQL
    VS CODE (Maven)


3. Modules

i. Model Class (Entity)
        Represents a record (e.g., Student)
        class Student {
            int id;
            String name;
            int age;
        }

ii. Collection Layer (Temporary Storage)
        Use ArrayList<Student>
        Store data in memory

iii. Service Layer (Business Logic)
        Handles:
        Add data
        Update data
        Delete data
        View data

iv. DAO Layer (Database Access)
        Handles:
        Insert into DB
        Update DB
        Delete from DB


v. JDBC Connectivity Module
        Establish connection
        Execute SQL queries
        Close resources

6. how to create maven project:

`Bash`:
mvn archetype:generate -DgroupId=com.example -DartifactId=CollectionSyncProject -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false

`Add Dependency`:
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>8.3.0</version>
</dependency>


`how Run`:
cd CollectionSyncProject
mvn compile
mvn exec:java -Dexec.mainClass="com.example.MainApp"
